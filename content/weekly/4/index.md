## 写在前面

这周在企鹅岛上班时，午后碰到了很漂亮的云隙光。随后迎来国庆假期，回武汉在小仓吃了鹅肝手握。最近为了学习 LLM on-device 推理，又把《奔跑吧 Linux 内核》翻了出来。

## 企鹅岛的午后

{{< weekly-photo src="penguin-island-sunlight.jpg" alt="企鹅岛午后阳光穿过云层照向海面" caption="企鹅岛 · 工作日午后" anchor="Center" >}}

那天是一个普通的工作日午后，海边的云很厚，阳光刚好从云层的缝隙里落下来，海面、远处的码头和天边一起被照亮，非常漂亮。

天气没有完全放晴，反而让光束变得更明显。企鹅岛这边能看到码头和远处的海面，和平时晴天里的感觉不太一样。

## 回武汉吃小仓

{{< weekly-photo src="xiaocang-foie-gras-sushi.jpg" alt="武汉小仓的鹅肝手握" caption="武汉小仓 · 鹅肝手握" anchor="Center" >}}

国庆还是回了一趟武汉，在小仓吃到的鹅肝手握非常好吃。鹅肝本身很香，表面带一点焦香，配上米饭和鱼籽，一口吃下去很满足。

## 本周书籍：《奔跑吧 Linux 内核》

{{< weekly-photo src="linux-kernel-book.jpg" alt="《奔跑吧 Linux 内核》第 2 版卷 1：基础架构" caption="《奔跑吧 Linux 内核》第 2 版 · 卷 1：基础架构" anchor="Center" >}}

最近在学习 LLM on-device 推理，过程中又碰到了不少内存和系统层的问题，于是重新翻了一些 Linux 内核的知识。

《奔跑吧 Linux 内核》以前看过，现在重新读起来依然很适合作为入口。接下来打算把内存管理相关的内容再系统过一遍，尤其是虚拟内存、页分配和内存回收，再回头看 on-device LLM 的内存占用与恢复行为。

## 周日的一次意外

周日意外受了点伤，去门诊处理以后，才想起来之前在支付宝买过门诊险。提交材料后报销了 **80%**，这是第一次很直接地感觉到保险确实还挺有用。

这次之后，我又补了一份长期医疗险，主要用来覆盖住院费用。现在门诊和住院分别有一份保障。
